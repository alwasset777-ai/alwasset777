# تطبيق مكتب الوسيط 777 — قاعدة بيانات المكتب

تطبيق قابل للتثبيت (PWA) يعمل على الآيفون، الأندرويد والماك بوك، **بدون إنترنت**.
البيانات (العقارات، الطلبات، الصور، الفيديو والمستندات) تُحفظ داخل الجهاز.

1. **إضافة عقار**: 89 نوعا من العقارات بالمغرب، 144 مدينة بأحيائها (مع إضافة أحياء جديدة)، خانات خاصة بكل نوع، المالك والوسيط، السعر من/إلى، المساحات، الصور/الفيديو/المستندات، وصف تلقائي.
2. **إضافة طلب**: معلومات الزبون + تفاصيل الطلب والمتابعة.
3. **المطابقة الذكية**: نسبة تطابق % مع الأسباب، وإرسال العرض عبر واتساب.
4. **البحث في الأعلى**: بحث فوري بالعربية والفرنسية + فلترة متقدمة.

## التثبيت
- آيفون (Safari): مشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية»
- أندرويد (Chrome): ⋮ ← «تثبيت التطبيق»
- ماك (Safari): File ← «Add to Dock» — أو Chrome: أيقونة التثبيت في شريط العنوان

الرابط بعد النشر: `https://alwasset777-ai.github.io/alwasset777/bureau/`

## المزامنة السحابية (الهاتف ↔ الماك)
1. أنشئ مشروعا مجانيا على [supabase.com](https://supabase.com).
2. SQL Editor ← الصق محتوى `supabase.sql` ← Run (مرة واحدة فقط).
3. Project Settings ← API: انسخ **Project URL** و **anon public key**
   (يمكن وضعهما في `docs/app/config.js` لتُملأ تلقائيا).
4. في التطبيق: الإعدادات ← المزامنة السحابية ← «إنشاء حساب جديد» ثم «دخول».
5. على كل جهاز آخر: نفس الحساب ← «دخول». كل شيء يُزامن تلقائيا (عند الحفظ، كل 3 دقائق، وعند عودة الإنترنت).

- كل حساب يرى بياناته فقط (Row Level Security)، والصور في مخزن خاص.
- الصور تُنزّل على الجهاز الآخر عند فتحها فقط (توفير الإنترنت).
- الخطة المجانية لـ Supabase تحدد حجم الملف الواحد بـ 50MB تقريبا: الفيديوهات الأكبر تبقى على الجهاز الذي أُضيفت منه.
