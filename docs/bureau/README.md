# تطبيق مكتب الوسيط 777 — قاعدة بيانات المكتب

تطبيق قابل للتثبيت (PWA) يعمل على الآيفون، الأندرويد والماك بوك، **بدون إنترنت**.
البيانات (العقارات، الطلبات، الصور، الفيديو والمستندات) تُحفظ داخل الجهاز.

1. **إضافة عقار**: 89 نوعا من العقارات بالمغرب، 144 مدينة بأحيائها (مع إضافة أحياء جديدة)، خانات خاصة بكل نوع، المالك والوسيط، السعر من/إلى، المساحات، الصور/الفيديو/المستندات، وصف تلقائي.
2. **إضافة طلب**: معلومات الزبون + تفاصيل الطلب والمتابعة.
3. **المطابقة الذكية**: نسبة تطابق % مع الأسباب، وإرسال العرض عبر واتساب.
4. **البحث في الأعلى**: بحث فوري بالعربية والفرنسية + فلترة متقدمة.

## التثبيت
- آيفون (Safari): مشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية»
- أندرويد (Chrome): ⋮ ← «تثبيت التطبيق»
- ماك (Safari): File ← «Add to Dock» — أو Chrome: أيقونة التثبيت في شريط العنوان
