Installer sur vos appareils

iPhone

  1. Ouvrez le lien de VIDOMIDO dans Safari.
  2. Touchez le bouton Partager.
  3. Choisissez « Sur l'écran d'accueil », puis « Ajouter ».

Mac

  1. Ouvrez le lien dans Safari.
  2. Menu Fichier → « Ajouter au Dock ».
  3. Avec Chrome : menu ⋮ → « Caster, enregistrer et partager » → « Créer un raccourci ».

Huawei

  1. Ouvrez le lien dans le navigateur Huawei.
  2. Touchez le menu ☰ en bas.
  3. Choisissez « Ajouter à l'écran d'accueil ».
